# 🎬 Reel SaaS – Social Media Planning Platform

Reel SaaS is a full stack social media planning and content management platform built using the MERN stack. Users can generate content ideas, manage social media planning, and organize their workflow efficiently.

---

# 🌐 Live Demo

### Frontend
https://reel-saas-frontend.onrender.com

### Backend API
https://reel-saas-backend.onrender.com

---

# ✨ Features

- 🔐 User Authentication with JWT
- 🧠 AI-Based Content Idea Generation
- 📅 Social Media Content Planning
- 📱 Responsive User Interface
- ⚡ REST API Integration
- 🌍 Frontend & Backend Deployment
- 🔒 Protected Routes
- ☁ MongoDB Database Integration

---

# 🛠 Tech Stack

## Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM

## Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Mongoose

## AI Integration
- GROQ API

# 🚀 Installation & Setup

## Clone Repository

```bash
git clone https://github.com/yourusername/reel-saas.git
```

---

# 💻 Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# 🔧 Backend Setup

```bash
cd backend
npm install
npm start
```

Backend runs on:

```bash
http://localhost:5000
```

---

# 🔑 Environment Variables

## Backend `.env`

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GROQ_API_KEY=your_groq_api_key
PORT=5000
```

## Frontend `.env`

```env
VITE_API_BASE_URL=http://localhost:5000/api
```

For production:

```env
VITE_API_BASE_URL=https://your-backend-url.onrender.com/api
```

---

# 📌 API Endpoints

## Authentication
- POST `/api/auth/signup`
- POST `/api/auth/login`

## Content Generation
- POST `/api/generate`

## User Data
- GET `/api/user`
